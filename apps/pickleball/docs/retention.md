# Retention — Dinkline

This is a tool, not a game. People come back because open play happens every week, on a fixed day.
- **Return reason 1 — the group is saved.** Settings → "Same group, fresh start" puts last week's names back in line in one tap. Typing 14 names again is what makes people quit a tool (guess).
- **Return reason 2 — the organizer role.** One person runs it; the others see it working and ask "what app is that?" Growth is word of mouth at the court (guess).
- **No streaks, no guilt notifications, no badges.** Optional later: one local reminder on the group's play day ("Open play today at 9") — only if the user turns it on.
- **Difficulty:** none (a tool). Speed is the "difficulty": adding a name must take under 3 seconds, starting a court 0 taps.
- **Numbers to track (when analytics is added, anonymous, closed event list):** session started, game ended (count), players count, courts count, scorer used yes/no, rule used. Week-1 and week-2 return per device.
