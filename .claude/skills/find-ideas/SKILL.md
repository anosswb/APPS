# /find-ideas [audience or theme]
1. Read `playbook/00-anass.md` (unfair advantages), `playbook/02-idea-hunting.md`, `IDEAS.md` (do not repeat what is there) and the newest `research/` file.
2. Send the `scout` agent out with 2–4 clear questions (store charts by small makers, search dropdown phrases, complaint threads, open-source mechanics). Run them side by side. You keep only their tables.
3. Keep ideas that fit the rails: Android earns from ads, iPhone from purchases, no server, one person, 3–6 weeks.
4. For each kept idea write: one line, the special thing ("the only one that…"), first proof with links, a first score (mark P or G), and how it earns.
5. Give Anass ONE table of at most 5 ideas, best first, and your pick with the reason in two lines.
6. Add them to `IDEAS.md`. Save new facts to a new dated file in `research/`.
