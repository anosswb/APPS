---
# /mine-reviews <app 1>, <app 2>, …
1. Start the `review-miner` agent with the app names and the target countries.
2. Save its report in the app's repo as `research/reviews-<date>.md` (or in this repo under `research/ideas/` if there is no app repo yet).
3. Give Anass 6 lines: the 3 things users hate most, the gap sentence, and the 2 rules that change our plan.
4. Put the "5 rules for our app" into the app's `docs/brief.md`.
