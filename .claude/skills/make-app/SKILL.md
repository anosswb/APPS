# /make-app [idea name or number]
1. Read `CHEATSHEET.md`. It is the path. Follow it in order.
2. If the idea is one of the 20, read its brief in `briefs/` (index: `briefs/README.md`). It is a starting draft: proof from steps 2 and 3 can change it.
3. Find where this app is: read its `PROGRESS.md` (or this repo's, if the app has no repo yet). Name the current step number.
4. Do that step fully, using the skill it names. Open only the playbook page that step needs.
5. At a ⏸ gate: stop, show Anass what the table says he should see, ask the one question. Do not go on without his answer.
6. Write the step number and the result in `PROGRESS.md` before ending the session (`/wrap-up`).
No idea given: take the top unbuilt one from `IDEAS.md`, say why in 3 lines, and start at step 1.
