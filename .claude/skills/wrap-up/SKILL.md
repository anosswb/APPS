# /wrap-up
1. Update `PROGRESS.md`: done, next (in order), blocked. Write it so a new session with no memory can continue.
2. Add rows to `DECISIONS.md` for every choice made, with the reason and who chose.
3. New facts with sources go in a new dated file in `research/`. A lesson that would have saved a day goes in `playbook/13`. Something new about how Anass thinks goes in the log of `playbook/00`.
4. Run the checks that fit what changed. Commit with a clear message. Do not push without Anass's yes.
5. Tell Anass in 3–6 lines: what works now, what to try on his phone, the one thing you need from him.
